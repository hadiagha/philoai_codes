# PhiloAI codes

This repo holds the code behind every number in the videos of [**PhiloAI | AI From Scratch**](https://www.youtube.com/@philo_ai).

Each video has its own folder. The code is small, from scratch and plain Python, so you can read it in one sitting and check every result yourself.

| Folder | Video |
|---|---|
| [`rl-basics/`](rl-basics/) | *Reinforcement Learning From Scratch: From a Dog's Treat to ChatGPT* |

Requirements: Python 3.8 or newer. Unless a folder says otherwise, no libraries are needed.
