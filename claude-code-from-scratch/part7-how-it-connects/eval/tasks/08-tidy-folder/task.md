Tidy the folder downloads/:

- move images (jpg, jpeg, png, gif, svg, in any letter case) into downloads/images/
- move documents (pdf, txt, docx, md) into downloads/docs/
- move data files (csv, json, xlsx) into downloads/data/
- then write downloads/INDEX.md with one line per file, like "- images/cat.png",
  sorted alphabetically

Don't change what's inside the files.
